# claims-streams-platform
Event-driven claims data platform on Kafka — CDC ingestion, stream enrichment, and replayable event sourcing, inspired by Optum's Kafka-as-a-Service architecture.

## Dev Dependencies
- uv is used for dependency management
- Docker is used for containerization

## Running the app
1. Set your own values in .env based on .env-example
2. Run docker-compose up -d
3. Navigate to http://localhost:8000 to see webclient
